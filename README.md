# Kalkulator Czasu Jazdy (Drive Time Calculator)

Aplikacja webowa służąca do precyzyjnej kalkulacji efektywnego czasu jazdy na podstawie harmonogramu (wykazu). Narzędzie automatyzuje proces rozliczania czasu pracy, eliminując błędy wynikające z ręcznych obliczeń, szczególnie w przypadkach pracy zmianowej.

## 🚀 Funkcjonalności

Aplikacja przetwarza dane wejściowe i zwraca czas jazdy netto, oferując następujące możliwości:

* **Precyzyjne obliczenia czasowe:** Kalkulacja czasu na podstawie godziny wyjazdu (stacja rozpoczęcia pracy) oraz godziny przyjazdu (stacja zakończenia pracy).
* **Obsługa postojów:** Możliwość wprowadzenia sumarycznego czasu postoju, który jest automatycznie odliczany od całkowitego czasu służby.
* **Obsługa przełomu dób (Midnight Crossing):** Zaimplementowany algorytm poprawnie interpretuje i oblicza czas pracy obejmujący zmianę daty kalendarzowej (tzw. łamanie doby), np. służby nocne rozpoczynające się jednego dnia, a kończące kolejnego.

* Weryfikację przypadków brzegowych (edge cases).
